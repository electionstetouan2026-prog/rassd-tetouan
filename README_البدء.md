# دليل البدء — منصة رصد تطوان

## تنبيه مهم: اشتراك Claude Pro / ChatGPT Plus ماشي كافي

اشتراكاتك الحالية (Claude Pro، ChatGPT Plus) هي اشتراكات **محادثة** (chat) —
كتخولك تهضر مع Claude/ChatGPT فالواجهة، لكن ما كتعطيكش "مفتاح API" باش
الكود ديالك يقدر يستدعي النموذج برمجيا. هادشي عندو حساب منفصل تماما،
عادة بفوترة على حساب الاستعمال الفعلي (غالبا رخيصة جدا للحجم ديالنا —
دراهم معدودة فالشهر، ماشي 100,000 درهم).

خاصك تدير 3 حسابات API منفصلة (كل واحد فيهم عندو باقة مجانية أو رخيصة تكفي البداية):

1. **Google AI Studio** (لـ Gemini) → https://aistudio.google.com/apikey
   - باقة مجانية سخية، هي المزوّد الأساسي المقترح للتنقيط.
2. **Anthropic Console** (لـ Claude كـ fallback) → https://console.anthropic.com
   - خاصو رصيد ($5 بداية كافية بزاف لهاد الحجم).
3. **OpenAI Platform** (لـ GPT كـ fallback ثاني) → https://platform.openai.com/api-keys
   - نفس الشي، رصيد صغير كافي.

وحساب واحد لقاعدة البيانات:

4. **Supabase** → https://supabase.com (مجاني، أنشئ مشروع جديد، سمّيه rassd-tetouan)
   - من Project Settings → API: خد `URL` و`anon key` و`service_role key`
   - من SQL Editor: نسخ ولصق محتوى ملف `supabase/schema.sql` كامل وشغّلو مرة وحدة

## خطوات التشغيل محليا

```bash
cd rassd-tetouan
cp .env.example .env.local
# عبي .env.local بالمفاتيح فوق
npm run dev
```

افتح http://localhost:3000 — غادي تشوف لوحة بمصدرين RSS متحقق منهم فعليا
(Hespress، اليوم24) ومؤشر "آخر جمع" حقيقي (بلا أي رقم مزخرف).

جرب الجمع يدويا: افتح http://localhost:3000/api/collect فالمتصفح —
غادي يجمع من المصدرين ويسجل النتيجة فقاعدة البيانات مباشرة.

## شنو تم بناؤه دابا (اليوم 1)

- ✅ قاعدة بيانات كاملة: مصادر، عمليات جمع، إشارات، مستخدمين/أدوار، سجل تدقيق append-only
- ✅ جمع RSS آلي حقيقي من مصدرين متحقق منهما (وليس مزخرفا)
- ✅ مؤشر "آخر تحديث" مبني على توقيت حقيقي من قاعدة البيانات
- ✅ طبقة تعدد مزودي AI مع fallback (Gemini → Claude → OpenAI)
- ✅ جدول `mentions` جاهز لاستقبال إدخال يدوي شفاف لفيسبوك/انستغرام
  (عمود `uploaded_by` إلزامي لأي إدخال يدوي — بدون إدخال خفي)

## الباقي (اليوم 2-3)

- واجهة الإدخال اليدوي الشفاف لفيسبوك/انستغرام
- pipeline التحليل: فلترة جغرافية (داخل/خارج نطاق تطوان) + تنقيط التهديد بالشفافية
  (نفس مبدأ "لماذا هذا التقييم" اللي كان جيدا فـ polibrand)
- فصل توليد الرد عن النشر (بلا نشر آلي مباشر — نفس المبدأ الجيد المحفوظ)
- صفحة Ciblage (إدارة كلمات المراقبة)
- تسجيل دخول (Supabase Auth) + واجهة إدارة المستخدمين
- نسخة heuristic بسيطة من Coordination (كشف تكرار نفس المحتوى من حسابات متعددة)

## نشر على الإنترنت (Vercel)

```bash
npm i -g vercel
vercel login
vercel
```
زيد نفس متغيرات .env.local فـ Vercel → Project Settings → Environment Variables.
ملف vercel.json معدّ مسبقا باش يشغّل الجمع تلقائيا كل 15 دقيقة (Vercel Cron).
